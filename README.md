### 🛠️ Setup Checklist (For First-Time Deployment)

1. [ ] **Upload Banner SVGs**: Generate your `dark.svg` & `light.svg` using `MASTER_PROMPT.md` and save them in the `assets/` folder of `Darshan7075/Darshan7075`.
2. [ ] **Enable Actions Permissions**: Go to **Settings -> Actions -> General -> Workflow permissions** and select **Read and write permissions**, then click **Save**.
3. [ ] **Run Snake Workflow**: Trigger `.github/workflows/snake.yml` manually under **Actions** tab or wait for the automatic cron.
4. [ ] **Deploy Vercel Stats (Optional for high reliability)**:
   - Create GitHub Personal Access Token (classic) with `repo` scope.
   - Fork `anuraghazra/github-readme-stats`.
   - Deploy to Vercel and set `PAT_1` environment variable.
   - Update the Vercel URL in `README.md` to your self-hosted Vercel domain.
